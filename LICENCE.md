## 🧩 About

**2XKO Mod Menu** is a curated list of 2XKO open-source tools:

- **Overlays** — on-screen helpers, layout notes, frame data viewer, training presets
- **Quality-of-Life Helpers** — combo catalog, character manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Training Presets — practice from any reset point
- Show Hitboxes — visualize attack and hurtbox ranges
- Replay Notes — record and review combo runs
- Playback Speed — adjust training playback for study (0.1x to 5x)

### Wallhack
- Character Catalog — browse characters, colors, and tags
- Custom Skin Notes — organize player cosmetics
- Input Display — improved input visibility during study

### Aimbot
- Training Mode Notes — segment study on any matchup
- Reset Control — manually reset positions mid-set
- Combo Buffer Notes — chain complex maneuvers in the lab
